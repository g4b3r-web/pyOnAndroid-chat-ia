Recursos de IA no PyOnAndroid

Para utilizar os recursos de Inteligência Artificial disponíveis no PyOnAndroid, é necessário instalar o LunusDroid.

Como ativar os recursos de IA

O LunusDroid fornece os componentes necessários para executar os recursos de IA utilizados pelo PyOnAndroid.

  1. Baixe o APK do LunusDroid pelo botão abaixo.
  2. Instale o aplicativo em seu dispositivo Android.
  3. Abra o LunusDroid pelo menos uma vez.
  4. Volte para o PyOnAndroid e utilize os recursos de IA.
⬇ Baixar LunusDroid
⚠️ O Android pode solicitar permissão para instalar aplicativos de fontes externas. Autorize a instalação para o navegador ou aplicativo utilizado para fazer o download.
